# 界面与布局

所有窗口与面板选项统一位于“首选项 → 界面与布局”。“应用”可以在不关闭设置窗口
的情况下预览更改。

## 面板

缩略图、信息和取色器面板支持停靠或窗内悬浮。悬浮面板可以拖动、调整大小、吸附到
主窗口或其他面板，并在下次启动时恢复位置和吸附关系。

“锁定面板布局”只防止误改停靠结构，不会禁止移动悬浮面板。

## 工具栏和窗口界面

工具栏项目可以显示、隐藏和排序。窗口变窄时，工具栏会保持单行并使用更紧凑的图标
与间距。菜单栏、工具栏和状态栏可以独立显示或隐藏；隐藏传统入口后仍保留紧凑的
主菜单按钮。

## 背景与主题

界面支持系统、浅色和深色主题。“系统”会使用 Qt 桌面平台插件从当前 KDE/GNOME
会话取得的控件风格、调色板和强调色；明确选择“浅色”或“深色”时使用 KDE Breeze
浅色/深色的内置配色，并在系统提供 Breeze 控件风格时优先使用它，否则回退到 Fusion。
画布背景可以使用纯色或透明网格；透明网格只用于显示 alpha 通道，不会修改图片内容。
