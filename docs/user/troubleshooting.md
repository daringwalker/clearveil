# 故障排查

## 图片无法打开

先在“帮助 → 支持的图片格式”中查看当前系统实际加载的解码插件。Clearveil 会区分
文件不存在、没有读取权限、缺少插件、文件损坏以及不支持的格式变体，并给出对应的
软件包安装建议。

## 大图片内存占用

超大图片优先使用 libvips 按需读取与分块显示。确认构建时检测到了 libvips，并在
问题报告中附上图片尺寸、格式、位深、Clearveil 版本和峰值内存。不要公开上传包含
敏感信息的原图，可以生成结构相似的测试图片。

## 无法选择图片文字

打开“帮助 → OCR 支持”。该页面会显示当前构建是否包含 Tesseract、已经发现的语言
模型，并根据当前 Linux 发行版列出准确的软件包和安装命令。安装语言模型后需要重启
Clearveil；Flatpak 中宿主机的软件包不一定对沙箱可见，应使用包含 OCR 与所需模型的
Clearveil Flatpak 构建。

## 主题没有完全切换

使用“系统”主题时，Clearveil 使用 Qt 桌面平台插件提供的当前控件风格、调色板和
强调色，并监听桌面门户的外观变更通知。请注明桌面环境、主题名称、Wayland/X11、
Qt 版本以及已安装的 Qt 平台主题插件。临时切换到明确的“浅色”或“深色”可帮助判断
是否为桌面主题集成问题。

## 报告问题

提交缺陷前请提供：

- Clearveil 和 Qt 版本；
- Linux 发行版、桌面环境和 Wayland/X11；
- 图片格式、像素尺寸和位深；
- 可重复步骤及预期/实际结果；
- 必要时提供截图或经过脱敏的测试文件。
