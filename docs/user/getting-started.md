# 开始使用

## 打开图片

可以通过以下方式打开图片：

- 在 Clearveil 中使用“打开图片”；
- 从文件管理器打开一个或多个图片；
- 将图片拖放到窗口；
- 将图片路径传给 `clearveil` 命令；
- 从剪贴板粘贴图片。

Clearveil 默认使用单实例。后续打开请求会转发到已有窗口，不会为每张图片创建一个
进程。用户主动打开的文件会加入“已打开的图片”；在“当前文件夹”中单击浏览不会
改变该列表，双击才会将图片加入。

## 基本查看

- 使用上一张/下一张按钮或配置的快捷键切换图片；
- 使用“适应窗口”让整张图片保持在画布内；
- 使用 `100%` 查看一个图片像素对应一个显示逻辑像素；
- 使用鼠标滚轮、组合键或触控板执行偏好设置中的动作；
- 按 `F11` 进入或退出全屏。

图片包含未保存修改时，切换文件或退出前会要求确认。

## 配置位置

Clearveil 使用 Qt 的平台设置路径保存偏好。具体位置会随发行版和桌面环境变化，
可在“关于 Clearveil”的诊断信息中确认版本和运行环境。默认情况下持久化缩略图
缓存关闭；启用后可在首选项中限制容量并清理。
