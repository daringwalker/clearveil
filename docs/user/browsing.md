# 浏览图片

## 已打开的图片

这是默认缩略图来源，按照用户明确打开文件的顺序保存跨目录图片列表。文件管理器、
打开按钮、菜单、拖放和命令行转发的图片都会进入该列表。

关闭缩略图项目只会从当前会话移除它，不会删除磁盘文件。

## 当前文件夹

切换到“当前文件夹”后，Clearveil 异步扫描当前图片所在目录。单击项目只在目录内
查看，不会自动加入“已打开的图片”；双击项目会明确打开并加入。

目录扫描结果、内存缩略图和滚动位置会尽量复用，来回切换来源不应反复扫描目录。

## 文件夹概览

“打开文件夹”会进入文件夹浏览界面，可使用后退、前进、上级目录、最近位置和收藏
位置。网格支持筛选、排序、多选和常用文件操作。

## 幻灯片

幻灯片使用当前导航序列。播放当前文件夹时，正在显示的缩略图会同步激活。随机、
间隔和全屏行为可以在首选项中配置。
