# Clearveil 回归验收集

高风险查看流程除了完整单元测试外，还按职责提供四个可独立运行的 CTest 测试组：

| 测试组 | 覆盖范围 |
|---|---|
| `clearveil_regression_navigation` | 最后请求优先、异步激活、相邻预读、大目录非阻塞打开、目录幻灯片选中同步 |
| `clearveil_regression_filmstrip` | 目录增量刷新、打开文件夹进入查看器、缩略图尺寸与缓存配置、双来源切换不重建 |
| `clearveil_regression_layout` | 桌面门户主题解析、菜单栏调色板、首选项即时应用与工具栏图标、顶部右键菜单和窗口拖动区域、窄工具栏图标稳定性、全屏组件恢复、悬浮面板、主窗口/面板间吸附、布局锁定与防抖持久化 |
| `clearveil_regression_input` | 默认滚轮/组合键、高精度触控板切图阈值、原生与触屏缩放/平移手势、状态语义名称、单实例 IPC 精确一次转发 |

配置阶段检测到相应工具时，还会自动注册三个 `packaging` 标签测试：AppStream
严格校验、Desktop Entry 校验和 Flatpak manifest 解析。它们只验证发布元数据，不能
替代实际安装、启动和卸载验收。

运行完整测试：

```sh
ctest --test-dir build --output-on-failure
```

只运行高风险回归组：

```sh
ctest --test-dir build -L regression --output-on-failure
```

## KDE Wayland 发布前人工验收

自动化测试通过后，在测试机使用浅色和深色主题各执行一次：

1. 从文件管理器连续打开不同目录的多张图片，确认只复用一个进程，并保持“已打开的图片”顺序。
2. 打开包含至少 1000 张图片的目录，快速连续切换 30 张图片，界面不冻结，最终画面、缩略图选中项和序号一致。
3. 在“已打开的图片”和“当前文件夹”之间反复切换，目录不重复扫描，滚动位置不意外跳到中间。
4. 调整横向和纵向缩略图面板尺寸，文件名、缩略图、滚动条和关闭入口不重叠或抖动。
5. 解锁布局，将信息、取色和缩略图面板分别浮动后重新锁定；面板保持可见，重启后恢复位置。
6. 在最小窗口宽度、全屏和无边框模式间切换，工具栏保持单行且图标不更换图形；缩略图来源按钮仅改变激活底色，隐藏组件退出全屏后正确恢复。
7. 修改主题或缩略图栏设置后点击“应用”，确认界面立即更新且首选项窗口保持打开；再修改但点击“取消”，确认未应用的修改被放弃。
8. 对裁剪、取色、幻灯片、缩放锁定各完成一次键盘和鼠标操作，确认状态反馈与当前图片同步。

发布包还需在干净 KDE Wayland 和 GNOME 环境分别验证安装、MIME 关联、升级、卸载和缺失解码库提示。
