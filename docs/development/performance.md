# 性能基准

`clearveil_thumbnail_benchmark` 提供可重复的缩略图流水线基准。它在临时目录生成
固定种子的 1280×720 JPEG 语料，分别测量：

1. 持久化缓存关闭时的新会话缩略图生成；
2. 首次填充持久化缓存；
3. 新模型复用持久化缓存。

基准不会读取或修改用户的 Clearveil 缓存。

```bash
QT_QPA_PLATFORM=offscreen \
  ./build/clearveil_thumbnail_benchmark \
  --images 200 --runs 3
```

使用 `--json` 可输出机器可读结果。CI 或固定测试机可以设置回归门槛：

```bash
QT_QPA_PLATFORM=offscreen \
  ./build/clearveil_thumbnail_benchmark \
  --images 200 --runs 5 \
  --max-session-median-ms 900 --json
```

超过门槛时进程返回状态码 2。绝对耗时会受到 CPU、存储、Qt 插件版本和系统负载
影响，因此门槛应当基于同一台基准机的多次结果设置。

2026-07-27 的开发环境基线：

| 模式 | 200 张图片耗时 |
|---|---:|
| 仅会话缓存，中位数 | 573 ms |
| 首次填充持久化缓存 | 1324 ms |
| 持久化缓存复用，中位数 | 120 ms |

这组数据用于发现后续提交的相对回退，不代表所有用户机器上的性能承诺。

## 主图解码基准

`clearveil_image_decode_benchmark` 生成固定种子的 Display P3 JPEG 语料，测量完整读取、
自动方向和到 sRGB 的色彩转换。它输出每轮耗时、解码器内部平均耗时、每秒图片数和
每秒百万像素数：

```bash
./build/clearveil_image_decode_benchmark \
  --images 6 --runs 3 --width 1920 --height 1080 --json
```

可用 `--max-median-ms` 设置 CI 中位耗时门槛。2026-07-27 开发环境基线为每轮 6 张
1920×1080 图片 120 ms，约 50 张/秒或 103.68 MP/s；18 次解码均执行了 Display P3
到 sRGB 转换。这是相对回归基线，不是跨硬件性能承诺。

## 主图内存缓存

主图异步加载由 `ImageLoadController` 管理。它只交付最新请求，通过停止令牌通知
正在运行的后端，并在
后台预读相邻图片。内存缓存默认上限为 256 MiB，可在“首选项 → 缩略图栏”中配置为
16–4096 MiB；缩小上限时会立即淘汰超出预算的内容。该缓存只存在于当前进程，
退出 Clearveil 后清空，不会写入磁盘。

`clearveil_tests` 使用可注入的确定性解码器验证最新请求、运行中取消、缓存命中、预读
复用以及缓存范围限制。Qt `QImageReader::read()` 本身不可中断；当前检查点位于读取
前后和色彩转换前后。

## 超大图片

估算 RGBA 解码内存达到 128 MiB 时，主图和缩略图都改用 libvips。首次打开只生成
最大边 2048px 的受限预览；缩放未超过预览原生比例时不会建立随机访问后备。继续放大
后，PNG 等顺序格式会建立自动删除的临时文件，画布只缓存当前可见的 512px 瓦片。
切换到其他图片时会立即释放旧图的随机访问流水线和临时后备，但保留最大边 2048px
的轻量预览；返回时主图直接命中预览缓存，只有再次放大才重建随机访问后备。该临时
文件不是持久化缩略图缓存，也不会跨会话保留。

主图正在生成大图预览时，两个缩略图模型会暂缓同一路径的解码，并在主图完成后直接
缩放其预览，避免主图和缩略图并发执行两次 `vips_thumbnail`。libvips 的全局运算缓存
关闭，缓存与生命周期统一由 Clearveil 的主图/缩略图/瓦片缓存控制。同一活动大图的
随机流水线仍会复用：5760×15285 PNG 实测首次区域约 637–638 ms，随后相邻区域约
5 ms；释放流水线约 24–26 ms，重新放大时约 643–648 ms 重建，过程中没有 GLib 告警。

瓦片调度按视口中心优先，且线程池只提交当前一个区域；快速平移或缩放时，尚未开始的
旧队列会被最新视口替换，最多只需等待一个已执行中的旧区域结束。

2026-07-30 使用 5760×15285 RGB PNG（原始 RGBA 约 336 MiB）测量：旧 Qt 整图路径
稳定约 470 MiB；接入主图大图后端但缩略图仍走 Qt 时，稳定约 129 MiB、启动峰值仍约
472 MiB。修复缩略图重复整图解码后，本地 offscreen Release 稳定/峰值约 140 MiB；
KDE Wayland 测试机 Release 构建适应窗口约 176 MiB，100% 可见区域分块完成后约
199 MiB、峰值约 206 MiB。切换到一张 1366×768 PNG 后，随机访问后备文件描述符从
1 降为 0，RSS 约 181 MiB（仍包含为快速返回而保留的轻量大图预览）。随机访问临时
后备约 252 MiB，位于磁盘而非匿名内存。
