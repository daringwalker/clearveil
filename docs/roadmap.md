# Clearveil 开发路线

“完成”均要求自动化测试通过，并在 KDE Wayland 测试机完成真实 GUI 验收。

- [x] 打开图片、命令行路径、拖放、剪贴板图片
- [x] 单进程复用；一次打开多张图片组成独立浏览序列
- [x] 默认按打开顺序维护跨目录图片列表；打开文件夹时自然排序
- [x] 上一张/下一张、可停靠缩略图栏
- [x] 适应窗口、100%、连续缩放、拖拽平移
- [x] 旋转、翻转、撤销/重做、另存为
- [x] 全屏、状态信息、系统/亮/暗主题与偏好持久化
- [x] 在 KDE Wayland 测试机完成验收

## M2：格式、性能与可靠性

- [x] 独立主图解码服务、停止令牌检查点和固定语料性能基准

## 范围取舍

- 评分、标签和注释不属于 Clearveil 的产品范围；现有 EXIF/IPTC/XMP 只读展示保留。
- 多颜色通道查看不作为首个稳定版的验收项。该能力主要面向设计和诊断场景，
  对日常浏览价值有限；待稳定版完成后再根据真实需求评估。
- 当前缩放显示在 100% 时保持原始像素，其他比例使用平滑插值，已经满足普通图片
  查看需求；不为追齐功能清单增加插值算法选择。
