# ADR 0001：默认使用单实例

- 状态：已接受
- 日期：2026-07-31

## 背景

用户经常从文件管理器连续打开多个图片。如果每次打开都创建独立进程和窗口，图片
之间无法连续导航，也会增加内存和窗口管理负担。

## 决策

Clearveil 默认只运行一个应用实例。后续进程通过受当前用户限制的本地 IPC 将一个或
多个绝对路径转发给已有实例，然后退出。已有窗口负责显示、加入“已打开的图片”并
切换到最新请求。

## 影响

- 多文件打开顺序必须稳定，消息只处理一次；
- IPC 必须限制消息尺寸、路径数量和访问用户；
- 测试需要隔离服务名，避免并行运行时互相影响；
- 将来如增加显式“新窗口”，也应优先在同一进程内管理多个窗口。
