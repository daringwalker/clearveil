# ADR 0003：悬浮面板使用窗内覆盖层

- 状态：已接受
- 日期：2026-07-31

## 背景

Wayland 通常不允许应用任意设置顶层窗口的全局位置。将工具面板实现为独立顶层窗口，
难以可靠地相对主窗口定位、吸附和恢复，也会受到不同窗口管理器策略影响。

## 决策

Clearveil 的“悬浮面板”默认实现为主窗口内容区域中的覆盖层，而不是独立顶层窗口。
面板拥有自己的标题、抓取区域、细边框、调整尺寸入口和停靠入口，可以吸附到主窗口
及其他悬浮面板。

## 影响

- 面板坐标相对主窗口保存，可跨 Wayland/X11 一致恢复；
- 主窗口移动时面板自然随之移动，主窗口缩放时保持吸附关系；
- 布局锁定只限制停靠结构，不禁止移动悬浮面板；
- 覆盖层必须使用不透明背景和明确边界，避免后方画布穿透；
- 面板不能脱离主窗口可用区域，这是可预测定位换来的限制。
