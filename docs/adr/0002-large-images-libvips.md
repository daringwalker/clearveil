# ADR 0002：使用 libvips 处理超大图片

- 状态：已接受
- 日期：2026-07-31

## 背景

将超长截图或高分辨率图片完整解码为 `QImage`，内存通常按宽 × 高 × 每像素字节数
增长，远高于压缩文件大小。仅降低缓存上限不能解决当前文档必须持有完整像素的问题。

## 决策

libvips 是 Clearveil 的必需依赖。超过阈值的图片使用受限预览和可随机读取的图片源，
查看区域按需读取并通过有界分块缓存复用；导出尽量使用流式管线。普通图片仍可使用
Qt 图片插件，保留动画、多帧和发行版扩展格式能力。

## 影响

- 图片文档必须区分完整内存图片和 region-backed 图片源；
- 缩放、取色和编辑操作需要明确是否要求原始像素；
- 后端错误必须转换成用户可理解且可翻译的信息；
- 打包必须包含 libvips，并固定 Flatpak 依赖版本；
- 性能测试同时记录耗时和峰值内存，不能只比较解码速度。
