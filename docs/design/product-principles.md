# Clearveil 产品设计

## 定位

Clearveil 是“图片查看器优先”的 Linux 桌面应用，不做重型素材管理器，也不与
专业修图软件竞争。用户从文件管理器双击图片后，应在最短路径内完成浏览、比较、
缩放、查看信息和轻量修改。

## 设计原则

1. **画布优先**：窗口主体始终留给图片；工具栏轻量、可隐藏。
2. **所见即所得**：缩放、旋转、翻页和全屏操作立即反馈，不打开不必要的对话框。
3. **显式打开列表优先**：普通“打开图片”只把用户选中的图片追加到当前浏览序列，
   即使图片来自不同目录也可继续上一张/下一张；只有“打开文件夹”才载入目录内容。
4. **安全修改**：编辑先进入可撤销状态，退出或切换前处理未保存修改。
5. **Linux 原生**：Wayland、HiDPI、系统主题、桌面文件、回收站和文件管理器集成
   都是一等能力。
6. **可访问、可本地化**：所有操作有可访问名称和键盘路径；首发包含中文和英文。
7. **单进程优先**：文件管理器和命令行的后续打开请求交给现有主窗口；多文件构成
   一个浏览序列，不为每张图片创建进程或窗口。

## 主界面

从上到下分为四层：

- 紧凑工具栏：打开、上一张/下一张、缩放、适应、旋转、更多菜单。
- 图片画布：背景随系统/亮色/暗色主题变化；透明图片区域默认显示棋盘格，可在
  “视图 → 背景”中独立关闭；支持拖拽平移和指针中心缩放。
- 可折叠缩略图带：默认展示已打开图片，也可切换到当前文件夹，清晰标出当前项。
- 状态栏：文件名、像素尺寸、文件大小、序号和缩放比例。

默认布局使用底部横向缩略图栏、图标式顶栏，并将当前图片信息直接放入窗口标题。
顶栏不换行，也不把操作收进 Qt 的溢出菜单；接近窗口最小宽度时自动切换紧凑图标
和间距。
缩略图栏通过工具栏中的紧凑来源按钮在“已打开的图片”和“当前文件夹”之间切换，
不在缩略图区域常驻文字页签；普通打开图片时前者为默认值，直接打开文件夹时显示
自然排序后的第一张图片并自动使用当前文件夹来源。切换来源不会丢失跨目录的已打开
图片列表。
缩略图栏和信息面板可停靠到任意边缘并可浮动，满足不同窗口比例和使用习惯。
布局默认锁定，用户显式解除锁定后才能拖动工具栏或停靠面板，避免日常浏览时误操作。
主工具栏隐藏时，左上角显示独立的紧凑主菜单按钮，确保所有被隐藏部件始终存在
恢复入口。传统菜单栏默认隐藏，可在“视图”中独立开启；状态栏也可独立隐藏。
菜单栏和主工具栏的空白区域可直接拖动主窗口；按钮、菜单项和其他交互控件
不会被拖动手势抢占。在顶部区域右键只显示 Clearveil 的具名布局和组件开关，
不展示 Qt 为无标题面板生成的空白条目。
缩略图栏不展示冗余标题、来源文字栏或面板关闭按钮，只保留图片内容。
信息面板按“常规、EXIF、IPTC、XMP”等类别分组，相同类别不在每个属性名前重复，
分组支持展开与收起；布局锁定时不显示面板标题和关闭按钮。

空状态只显示“打开图片”和“打开文件夹”，不展示复杂导航树。“打开文件夹”直接进入
查看器；完整缩略图网格作为次级“文件夹概览”进入，并在概览期间隐藏底部缩略图栏，
避免同一批文件在中央网格和底栏重复出现。概览支持多选、文件拖出、加入已打开列表、
在文件管理器中显示，以及重命名、批量复制、移动和移到回收站；`F2` 与 `Delete`
分别提供重命名和回收站快捷路径。批量磁盘操作在后台串行执行，完成后只刷新受影响的
目录、已打开列表和当前图片，不冻结界面，也不重新扫描无关目录。概览顶部使用紧凑
图标提供返回查看器、文件夹后退/前进、上级目录和位置菜单；位置菜单集中展示收藏与
最近访问的文件夹，不常驻额外文字栏。`Alt+Left`、`Alt+Right` 和 `Backspace` 分别
对应文件夹后退、前进和上级目录。

## 默认交互

| 操作 | 行为 |
|---|---|
| `←` / `→`、鼠标侧键 | 上一张 / 下一张 |
| 鼠标滚轮 | 垂直滚动图片显示区域 |
| `Shift` + 鼠标滚轮 | 横向滚动图片显示区域 |
| `Ctrl` + 鼠标滚轮 | 以指针为中心缩放 |
| 左键拖拽 | 平移放大后的图片 |
| 双击画布 | 在适应窗口与 100% 间切换 |
| `0` / `1` | 适应窗口 / 100% |
| `+` / `-` | 放大 / 缩小 |
| `Ctrl+O` | 打开图片 |
| `Ctrl+Shift+O` | 打开文件夹 |
| `Ctrl+R` / `Ctrl+Shift+R` | 向右 / 向左旋转 |
| `F11` | 全屏 |
| `Space` | 幻灯片播放 / 暂停 |
| `Delete` | 移到回收站（需要确认，可配置） |

## 非目标

- 首个稳定版不提供图层、画笔引擎和复杂选区。
- 不建立专有图片库数据库，也不提供评分、标签和注释的写入、检索或管理；图片中
  已存在的 EXIF/IPTC/XMP 字段仍作为只读信息完整展示。
- 多颜色通道主要服务于印前、素材诊断等专业场景，不作为首个稳定版的必需能力；
  后续只有在不增加常驻界面复杂度且有明确用户需求时，才以临时查看模式加入。
- 不默认修改原图；无损操作可用时优先无损保存。

当前缩放策略已经满足日常查看：100% 时直接显示原始像素，其他比例使用平滑缩放。
首个稳定版不增加插值算法选项；像素画专用的最近邻显示或更高级算法只有在出现明确
需求和性能数据后再评估。

## 技术架构

- C++20 + Qt 6 Widgets，兼容 KDE Plasma、GNOME 与其他主流 Linux 桌面。
- `ImageDocument` 管理解码、修改状态、撤销和保存。
- `ImageSequence` 管理目录发现、格式过滤、自然排序和文件系统变化。
- `ImageCanvas` 负责显示几何、缩放、平移和透明背景，并分离源图与显示图；取色和编辑
  使用源图，绘制使用由色彩控制器生成的显示副本。
- `CanvasAppearanceController` 管理透明区域棋盘格动作和画布状态；棋盘格只绘制在
  图片范围内，关闭后透明像素直接显示主题画布背景。
- `SystemAppearanceController` 使用 Freedesktop 桌面门户读取并监听系统深浅色偏好；
  选择“系统”主题时，GNOME/KDE 中的偏好变更无需重启即可更新整个界面。
- `PanelLayoutController` 独立管理停靠面板的悬浮、锁定、默认位置和配置恢复；
  `MainWindow` 只负责顶层界面组合。
- `ApplicationSettings` 统一设置默认值、范围校验和持久化，`ActionRegistry` 统一
  动作 ID、工具栏布局与快捷键描述。
- `ImageSessionController` 分离已打开列表和目录预览状态，`FilmstripController`
  负责缩略图来源、选择及滚动状态，切换来源不会重新创建模型。
- `DirectoryScanService` 在独立线程池中枚举、过滤并自然排序目录，旧请求可取消，
  最近目录结果按目录修改时间保存在有界内存缓存中；当前文件夹缩略图和文件夹概览
  复用扫描结果，避免两套界面重复访问磁盘。`BrowserWidget` 独立保存各目录的选择和
  滚动位置；`FolderNavigationController` 管理后退/前进栈、最近位置和收藏位置，
  导航失败时不会破坏既有历史。
- `ImageLoadController` 隔离异步主图解码、最后请求优先、逻辑取消、相邻预读和
  有界内存缓存；大图缓存保留轻量预览、逻辑尺寸和区域源，首次同步打开与异步导航
  使用同一缓存，缓存容量可配置，默认 256 MiB，退出后清空。
- `DocumentWorkflowController` 统一当前文档、动画/多页帧、剪贴板图片、保存、外部
  文件监听与重载；`ViewerNavigationController` 统一异步切图的待处理索引、结果接入
  和基于实际激活路径的相邻预读，避免这些状态散落在主窗口中。
- `ViewerUiStateController` 根据文档、会话和加载状态统一计算动作可用性，并集中生成
  状态栏与窗口标题呈现；主窗口只提供当前状态输入，不再分别维护重复规则。
- `ImageDecoder` 统一安全尺寸限制、结构化解码错误、停止令牌检查点、源色彩空间保留
  和性能指标，为后续可选格式后端保留稳定的请求边界。
- `DisplayColor` 与 `DisplayColorController` 自动解析当前输出目标、异步生成显示副本并
  处理屏幕变化；Wayland 交给合成器输出转换，X11 可自动读取 colord，失败时静默回退
  sRGB，不要求用户选择 ICC 文件。
- `SlideshowController` 管理计时、顺序/随机导航及全屏生命周期；
  `ColorPickerController` 管理取色样本、格式化和画布/面板协调。
- `FileOperations` 统一重命名、复制、移动、回收站、文件管理器定位和外部应用启动，
  使用结构化结果报告失败并处理跨文件系统移动回退；
  `BrowserFileOperationsController` 独立负责文件夹概览中的确认、目标选择、后台批处理
  与结果汇总，`MainWindow` 只协调文档、会话和目录模型的状态更新。
- `ImageExportService` 统一普通保存和当前帧导出的原子编码；`DesktopIntegration`
  隔离打印渲染及 XDG Desktop Portal 壁纸请求。
- `ImageEditController` 统一旋转、翻转、裁剪、缩放、颜色调整、红眼及撤销/重做，
  返回可测试的命令结果并禁止直接修改动画或多页帧。
- `WindowModeController` 统一无边框、总在最前、全屏组件快照和窗口适应图片，避免
  顶层窗口同时维护互相影响的呈现状态。
- `SingleInstance` 通过用户级进程锁和本地套接字接收后续启动请求；通信仅允许当前
  用户访问；测试使用独立运行目录和实例名，不依赖宿主会话的运行时目录权限。
- 画布将触控板的细粒度像素滚动连续用于平移和缩放；配置为切图时先累计微小增量，
  达到阈值后才切换一张，避免一次手势跳过多张图片。
- 文件夹枚举与缩略图生成均不占用界面线程，并通过有界缓存控制内存。
- 持久化缩略图缓存是默认关闭的可选能力；启用时按源文件路径、大小、修改时间和
  缩略图尺寸失效，并按用户配置的磁盘容量在后台淘汰旧项。
- `FormatCapabilities` 从 Qt 图片 I/O 插件动态生成可读写矩阵，并统一驱动目录
  过滤、文件选择器、能力报告和打开失败诊断。
- 可选后端按能力加载：Qt Image Formats、KImageFormats、LibRaw、LittleCMS。
